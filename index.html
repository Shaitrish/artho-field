অ্যাপ ইনস্টল করুন

অ্যাপটি এখনো Play Store-এ নেই। নিচের লিংক থেকে সরাসরি ডাউনলোড করুন। Android 7.0 বা তার নতুন ফোনে চলবে।

⬇ artho-field.apk ডাউনলোড করুন

লিংক: https://github.com/Shaitrish/artho-field/releases/latest/download/artho-field.apk

  1. ফোনের Chrome-এ উপরের বাটন বা লিংকে চাপ দিন। ডাউনলোড শেষ হলে artho-field.apk ফাইলটি খুলুন।
  2. ফোন জানতে চাইলে “এই উৎস থেকে ইনস্টল করার অনুমতি দিন” (Install unknown apps) চালু করুন।
  3. Install চাপুন। Play Protect সতর্কবার্তা দেখালে More details → Install anyway চাপুন।
  4. ইনস্টল শেষে হোম স্ক্রিনে সবুজ তীর চিহ্নের Artho Field আইকন দেখবেন।

হোম স্ক্রিন চিনুন

লগইনের পর এই পাতাটি দেখবেন। প্রতিদিনের সব কাজ এখান থেকেই।

  • উপরে ডানে: চাঁদ/সূর্য আইকন দিয়ে লাইট ও ডার্ক মোড বদলান, ঘড়ি আইকনে ইতিহাস, তীর আইকনে সাইন আউট।
  • কাজের দিন কার্ড: আজকের তারিখ, অবস্থা (OPEN / SUBMITTED / MISSED), ট্র্যাকিং চলছে কিনা এবং শেষ লোকেশন কখন নেওয়া হয়েছে।
  • তিনটি ঘর: আজ কয়টি ভিজিট, কয়টি বই দিয়েছেন, কত টাকা খরচ।
  • Visits ও Expenses: + Add চেপে নতুন ভিজিট বা খরচ যোগ করুন। আগেরটায় চাপ দিলে সংশোধন করা যায়।

দিন শুরু করুন

মাঠে বের হওয়ার সময় কাজের দিন শুরু করুন। প্রথমবার ফোন কয়েকটি অনুমতি চাইবে, প্রতিটি ঠিকভাবে দিন।

  1. হোম স্ক্রিনে ▶ Start day চাপুন।
  2. লোকেশনের অনুমতি চাইলে While using the app দিন।
  3. এরপর সেটিংস খুললে Allow all the time (সবসময় অনুমতি দিন) বেছে নিয়ে ফিরে আসুন।
  4. নোটিফিকেশনের অনুমতি চাইলে Allow দিন।
  5. Allow running in background লেখায় চাপ দিয়ে ব্যাটারি সেভার থেকে অ্যাপটিকে বাদ দিন (Allow)।

দিন শুরু হলে কার্ডে সবুজ Tracking active লেখা আসবে এবং নোটিফিকেশনে “Artho Field: work day running” দেখাবে।

ভিজিট যোগ করুন

প্রতিটি স্কুল, কলেজ, মাদ্রাসা বা কোচিং ভিজিটের সময় সেখানে দাঁড়িয়েই এন্ট্রি দিন। তাতে জায়গার সঠিক লোকেশন থাকে।

  1. Visits কার্ডে + Add চাপুন।
  2. জায়গা (Place): অ্যাপ আপনার আশেপাশের (৩০০ মিটারের মধ্যে) আগের জায়গাগুলো দেখাবে। আগে গিয়ে থাকলে তালিকা থেকে বেছে নিন। তখন আগের ভিজিটের ব্যক্তি, স্কোর ও বই আপনা থেকেই বসে যাবে।
  3. নতুন জায়গা হলে New place at my location চাপুন। নাম লিখুন, ধরন বাছুন (School, College, Madrasa, Coaching…), ঠিকানা ও ফোন দিন।
  4. যার সাথে দেখা (Person met): আগের কেউ হলে নামের চিপে চাপুন। নতুন হলে নাম, পদবি (যেমন প্রধান শিক্ষক) ও ফোন নম্বর লিখুন।
  5. লিড স্কোর: ১ থেকে ১০ এর মধ্যে একটি সংখ্যা চাপুন।

৫–৭: আবার যোগাযোগ দরকার

স্পেসিমেন কপি ও সেভ

একই ভিজিট ফর্মের নিচে Specimen copies অংশে কোন বই কয়টি দিলেন তা লিখুন।

  1. শুরুতে আপনি সাধারণত যে বইগুলো দেন সেগুলো সাজেশন হিসেবে দেখাবে।
  2. অন্য বই লাগলে Show all চাপুন, অথবা Search books-এ নাম লিখে খুঁজুন।
  3. কোম্পানি অনুযায়ী দেখতে উপরের চিপ (Infinity, Mpbian…) চাপুন।
  4. প্রতিটি বইয়ের পাশে + / − চেপে সংখ্যা ঠিক করুন, অথবা ঘরে সংখ্যা লিখুন।
  5. Notes-এ ছাত্রসংখ্যা, সিদ্ধান্ত কে নেন, কবে আবার যেতে হবে ইত্যাদি লিখুন।
  6. সবশেষে ✓ Save visit চাপুন।
!

যে বই দিলেন শুধু সেটাই লিখুন। সেভ করলে সেই পরিমাণ বই অফিসের স্টক থেকে কমে যায়। ভুল হলে ভিজিটে চাপ দিয়ে সংশোধন করুন বা Delete visit করুন; তখন বই আবার স্টকে ফেরত যায়।

খরচ যোগ করুন

দিনের প্রতিটি কাজের খরচ আলাদা করে যোগ করুন।

  1. Expenses কার্ডে + Add চাপুন।
  2. খরচের ধরন বাছুন: Food (খাবার), Transport (যাতায়াত), Lodging (থাকা), Mobile (মোবাইল), Printing (প্রিন্ট), Other (অন্যান্য)।
  3. টাকার পরিমাণ লিখুন (শুধু সংখ্যা)।
  4. Note-এ বিস্তারিত দিন, যেমন “বাস ঠাকুরগাঁও → পীরগঞ্জ”।
  5. Save expense চাপুন।
✓

খরচ হওয়ার সাথে সাথেই এন্ট্রি দিন। রাতে মনে করে লিখলে ভুল হওয়ার সম্ভাবনা বেশি।

৮

আমার লোকেশন দেখুন

আজ আপনার কোন কোন লোকেশন রেকর্ড হয়েছে তা আপনি নিজেই দেখতে পারেন। অফিস যা দেখে, আপনিও ঠিক তাই দেখবেন।

  1. হোম স্ক্রিনে See my locations চাপুন।
  2. ম্যাপে সবুজ দাগ আজকের রুট, নম্বর দেওয়া পিন আপনার ভিজিট, নীল বিন্দু আপনি এখন যেখানে আছেন।
  3. নিচের তালিকায় প্রতিটি রেকর্ডের সময় ও এলাকার নাম থাকে।
  4. কমলা Waiting লেখা থাকলে সেটি এখনো পাঠানো হয়নি। নেট পেলে নিজে থেকেই চলে যাবে।

সমস্যা ও সমাধান

“No location for 45+ minutes” দেখাচ্ছে

ফোনের ব্যাটারি সেভার অ্যাপ বন্ধ করে দিচ্ছে। হলুদ সতর্কবার্তায় চাপ দিয়ে Allow দিন। Xiaomi, Oppo, Vivo, Realme ফোনে Settings → Apps → Artho Field → Battery → “No restrictions” করে দিন।

“Allow all the time” সেট করা নেই বলছে

Settings → Apps → Artho Field → Permissions → Location → “Allow all the time” বেছে নিন।

“waiting for network” লেখা আছে

কোনো সমস্যা নেই। নেট এলে লোকেশন নিজে থেকেই পাঠানো হবে। অ্যাপ খুললে বা নিচে টেনে রিফ্রেশ করলে দ্রুত যায়।

গতকালের ভিজিট যোগ করতে পারছি না

মধ্যরাতের পর আগের দিন বন্ধ হয়ে যায়। জরুরি হলে অফিসে জানান।

আশেপাশের জায়গা দেখাচ্ছে না

GPS চালু আছে কিনা দেখুন এবং খোলা জায়গায় দাঁড়ান। জায়গাটি আগে কেউ যোগ না করলে “New place at my location” দিয়ে যোগ করুন।

আবার লগইন করতে বলছে

নিরাপত্তার জন্য মাঝে মাঝে আবার লগইন লাগে। মোবাইল নম্বর ও অ্যাপ পাসওয়ার্ড দিয়ে লগইন করুন। জমে থাকা লোকেশন হারাবে না।

অ্যাডমিনের জন্য: অফিসার চালু করা

  1. artho.app-এ লগইন করে বাম মেনু থেকে Employee খুলুন।
  2. অফিসারের সারিতে ⋯ → Edit চাপুন।
  3. Field officer (can use the Artho Field app) টিক দিন।
  4. Set app password-এ অন্তত ৬ অক্ষরের পাসওয়ার্ড দিয়ে Submit চাপুন।
  5. অফিসারকে মোবাইল নম্বর, পাসওয়ার্ড এবং এই নির্দেশিকার লিংক পাঠান: https://shaitrish.github.io/artho-field/

সবার লাইভ লোকেশন, দিনের রুট, ভিজিট, লিড তালিকা ও খরচ দেখতে বাম মেনুর Field পাতায় যান।
